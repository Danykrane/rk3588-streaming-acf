# Тестовое задание: потоковая АКФ на RK3588

Основной ответ: **SOLUTION.pdf**. Редактируемый исходник: [SOLUTION.md](SOLUTION.md).
Граф: [SVG](docs/graph.svg) / [PNG](docs/graph.png).

В решении приведены трактовка формулы и допущения, дискретизация, граф,
оценки TOPS, памяти, параллелизма и срока разработки. Первая GPU-версия
предлагается с прямым суммированием; рекуррентная версия - альтернатива.

## Что проверено

CPU-прототип проверяет математическую модель и порядок строк кольцевой
матрицы. Эскиз OpenCL C проверен синтаксически и выполнением его скалярной арифметики на CPU. **На Mali-G610 код не запускался**;
драйвер прибора и OpenCL host-приложение не входят в этот расчётный ответ.
Профиль FP32 условен до согласования допустимой ошибки 64-битных данных.

## Воспроизведение

Python 3.10+; сторонние пакеты для расчётов и тестов не нужны:

```sh
python3 -m unittest discover -s tests -v
python3 reference.py
```

Дополнительная проверка при установленном Clang с поддержкой OpenCL C:

```sh
python3 tools/check_kernel.py
```

## Состав

- `reference.py` - эталон и потоковая модель в Python binary64.
- `tests/test_reference.py` - шесть тестов, включая более двух оборотов входного кольца.
- `acf.cl` - прямой расчёт одной строки в FP32; контракт host-стороны в комментарии.
- `tools/check_kernel.py`, `tests/kernel_host.c` - 16 500 сравнений FP32-ядра на CPU.
- `docs/VERIFICATION.md` - результаты проверок и ограничения.
- `tools/build_pdf.py` - сборка PDF из Markdown; нужны ReportLab, шрифты DejaVu Sans.
- `docs/graph.dot` - исходник графа Graphviz.

Все материалы хранятся локально. Внешний репозиторий не настроен.
