# Streaming ACF

Потоковая автокорреляция на C++20: вход 2 кГц, 500 частотных параметров
от 1 до 500 Гц, кольцевая матрица последних 2000 строк.
Доступны прямой расчёт и рекуррентное обновление суммы.

Для частоты f используются окно T = 1/f и задержка T/4. Дробная задержка
интерполируется линейно, крайний отсчёт окна взвешивается пропорционально
его дробной части. Это оконная АКФ, а не спектр мощности или банк фильтров.

## Сборка и тесты

Нужны CMake 3.23+, Ninja и компилятор C++20 с поддержкой `std::from_chars`
для вещественных чисел. Зависимости range-v3 и doctest закреплены сабмодулями.

```sh
git submodule update --init --recursive
cmake --preset mac-release
cmake --build --preset mac-release
ctest --preset mac-release
```

На Linux используйте `linux-release`. Также доступны пресеты `mac-debug`,
`linux-debug`, `mac-asan` и `linux-asan`. Для ASan/UBSan нужен совместимый
Clang/GCC; на macOS 26.6.2 проверен Clang 22.1.1. Системный AppleClang 17
на этой ОС зависал при инициализации ASan. Компилятор можно выбрать при
configure через `-DCMAKE_CXX_COMPILER=/path/to/clang++`.

## Запуск

```sh
./build/Darwin/mac-release/acf_cli < samples.txt > acf.csv
./build/Darwin/mac-release/acf_cli --int64 --recursive < samples.txt > acf.csv
```

Вход — числа, разделённые пробельными символами. По умолчанию принимаются
конечные значения double в [-1; 1]. Флаг `--int64` принимает знаковые целые
и масштабирует их на 2⁻⁶³; все 64 значащих бита при этом не сохраняются.
Выход остаётся нормированным: CSV без заголовка, 500 столбцов, строки
в порядке поступления. До прогрева соответствующего окна выводится `nan`.

Библиотека доступна как CMake-цель `acf::acf`. Процессор владеет буферами,
не копируется и не перемещается. `row(age)` возвращает неизменяемый span,
содержимое которого перезаписывается через `2000 - age` следующих отсчётов.
Объект должен жить дольше span; параллельный доступ требует синхронизации.

## Дополнительная проверка

Python 3.10+ и Clang позволяют проверить исходник OpenCL-ядра на CPU:

```sh
python3 tools/check_kernel.py
python3 -m unittest discover -s tests -v
```

`acf.cl` — эскиз FP32-ядра для GPU. Интеграция с OpenCL и прибором отсутствует;
на Mali-G610 код не запускался. C++-реализация работает на CPU в double.

Форматирование: clang-format 15, конфигурация в `.clang-format`.
